  {\color{wsorange}\bfseries What you will build}\par\smallskip
  In this workshop, you will start by working with Docker Compose to manage
  multi-container setups, then deploy and explore the Pedelec server-side system.
  You will learn to write Kubernetes manifests, interact with clusters using
  \wsClusterPlatform{} and kubectl, and create Deployments, Services, and
  Ingresses. By the end, you will have deployed a microservice architecture to
  the cloud and gained hands-on experience with scalable, containerized
  application management.\par\bigskip
